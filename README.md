# ⚔️ Встречи в Dota 2

Простой одностраничный сервис: вводишь два ID из Dota 2 (свой и чужой) — и видишь, сколько раз и когда вы встречались в матчах, в одной команде или на противоположных сторонах, с кем каким героем и кто победил.

## Как это работает

- Данные берутся из бесплатного [OpenDota API](https://docs.opendota.com) прямо из браузера — бэкенд не нужен.
- Мгновенная сводка даёт эндпоинт `/players/{id}/peers` (сколько игр вместе и друг против друга за всё время).
- Полный список встреч ищется честно: скачивается история матчей обоих игроков (`/players/{id}/matches`, постранично) и пересекается по `match_id`. Совпал ID матча — вы оба были в нём. Сторона (Radiant/Dire) определяется по `player_slot`, исход — по `radiant_win`.
- Учитывается лимит бесплатного API (~60 запросов в минуту): запросы идут по очереди, со стартовым запасом в 8 и дальше не чаще одного в секунду, при ответе 429 — пауза и повтор.
- Перед сканированием дешёвым запросом проверяется, что история матчей открыта у обоих игроков: если у одного она закрыта (приватный профиль или аккаунт не отслеживается OpenDota), второй не сканируется зря.

## Запуск

Это статика — достаточно открыть `index.html` в браузере. Удобнее через любой локальный сервер:

```bash
cd dota2-encounters
python -m http.server 8000
# http://localhost:8000
```

## Деплой

Положить три файла (`index.html`, `style.css`, `app.js`) на любой хостинг статики: GitHub Pages, Netlify, Vercel, Cloudflare Pages.

## Формат ID

Принимаются:

- ID Dota 2 / SteamID32 — например `70388657`;
- SteamID64 — `76561198030654385` (конвертируется автоматически);
- SteamID3 — `U:1:70388657`;
- ссылка на профиль opendota.com / dotabuff / steamcommunity.

## Возможности и ограничения

- **Три режима.** «Два игрока» — полная история встреч с датами и героями. «Разбор матча» — все 10 игроков матча и сколько раз ты встречался с каждым. «Невидимая тусовка» — уникальная фишка: находит людей, которых судьба подкидывала тебе в матчи снова и снова **без пати** (вы оба соло, сговориться было невозможно).
- «Тусовка» берёт топ-25 частых попутчиков из `/peers`, сканирует твою историю (до 10 000 матчей) и последние ~500 матчей каждого попутчика; случайной считается встреча, где твой `party_size = 1`. Порог «тусовочности» — 3 такие встречи; попутчики, с которыми все пересечения в пати, честно отмечаются как настоящие друзья.
- В режиме разбора матча на каждого игрока просматривается до ~2000 последних матчей (лимит страниц сканера), поэтому разбор занимает 20–40 секунд и не истощает лимит API (~40 запросов на матч). Игроки с закрытой историей помечаются отдельно.
- Результат можно расшарить ссылкой — параметры кладутся в URL (`?a=…&b=…&d=500` для игроков, `?a=…&mid=…` для матча).
- Глубина поиска: вся история, ~2000 или ~500 последних матчей каждого (глубже — дольше из-за лимитов API).
- Опция «включая матчи с ботами и кастомные режимы» добавляет незначимые для статистики матчи (`significant=0`).
- На «всю историю» действует предохранитель: не более 10 000 матчей на игрока.
- Персональные данные не собираются, всё выполняется в браузере; история героев кешируется в localStorage на 2 недели. Иконки медалей рангов — официальные (папка `icons/`, источник: Dota 2 Wiki).
